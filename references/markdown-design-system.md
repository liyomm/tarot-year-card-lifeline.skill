# Personal Tarot Map Markdown 设计系统

本规范用于所有 Markdown 报告，也作为 PDF 信息架构的对应底稿。它改变呈现方式，不改变 Mary K. Greer 年度牌、出生牌、九星群或 RWS 牌序算法。

第 02～04 章的牌名、牌位释义、关键词、象征、牌意和综合结论必须与 PDF 相同。第 02 章嵌入生命灵数图、命运牌图、旬区高亮图与宫廷牌图；第 03 章嵌入以性格牌为视觉中心的 `charts/personal_card_cloud.png`；第 04 章嵌入当前年度牌和前后年度牌。Markdown 直接使用同义 Unicode emoji。

## 固定阅读架构

报告只使用一个 H1：`# 🌙 Personal Tarot Map`，其后以正文显示“个人塔罗生命地图”和用户称呼。八个 H2 必须依次为：

1. `## 🪞 01｜我的塔罗身份卡`
2. `## 🔮 02｜我的个人塔罗象征语言`
3. `## 🧩 03｜把这些牌放在一起`
4. `## 📍 04｜我现在在哪里？`
5. `## 🗺️ 05｜我的终身塔罗图谱`
6. `## 📚 06｜0～100 岁年度牌查询表`
7. `## ✍️ 07｜年度复盘`
8. `## 📜 08｜方法依据与参考文献`

0～100 岁表是核心查询产品，不是附录：默认必须完整、展开、连续呈现 101 行。只有用户明确选择其他年龄范围时，才相应改变第 06 章标题和行数。

开头用简短导航说明两条路径：`🔮 READ` 按 01～04 阅读；`🗺️ LOOK UP` 按 05～08 查询。边界说明只在开头出现一次，正文用开放语气表达不确定性，不再插入系统提示式免责声明。

## 标题与组件

- H1 只用于主标题；H2 用于八个一级章节；H3 用于牌、循环、年龄段等二级主题。
- 禁止 H4、H5、H6。H3 以下使用粗体小标题、Callout、正文和列表。
- 核心牌用 `width="100%"`、`table-layout:fixed` 的 HTML 牌卡；同一牌承担多个角色时只展示一张图。每张牌只保留“它为什么是我的牌／牌面中的象征／这张牌对我意味着什么”三个内容模块。
- Mary 体系／原书材料使用 abstract 或 note Callout；现代解释使用 interpretation 或 tip；阴影使用 warning；反思使用 question；当前年度使用 important。
- 渲染器不支持自定义 Callout 时，回退到 Obsidian 通用的 `note`、`tip`、`warning`、`question`，保留 Callout 标题中的 Emoji 和语义。
- 分隔线只在主要章节转换确有帮助时使用，不在小节之间堆叠。

## 固定 Emoji 词典

`🌙` 总体；`🪞` 身份；`🔮` 塔罗综合；`🦁` 性格牌；`💗` 灵魂牌；`🌑` 隐藏／阴影；`☀️` 太阳；`🌙` 月亮；`🌅` 上升；`🎯` 命运牌；`👑` 潜力／宫廷牌；`🔢` 数字；`📅` 年度牌；`📍` 当前年份／年龄；`⏪` 上一年；`⏩` 下一年；`🗺️` 人生地图；`⭐` 用户提供的人生节点；`🔁` 重复周期；`🌀` Lifetime Loop；`↘️` Reset；`✨` 建设性资源；`⚠️` 风险；`💭` 反思；`📚` 查询表；`🧮` 计算；`✍️` 记录；`📜` 原书依据。

四花色固定为：`🔥 权杖`、`🏆 圣杯`、`🗡️ 宝剑`、`🪙 星币`。不得随机换用近义 Emoji。`⭐` 只能标用户提供的节点，`📍` 只能标当前年份／年龄；两者重合时显示 `⭐📍`。

## 0～100 岁全宽查询表

分段固定为：🌱 0～9、🎒 10～19、🌿 20～29、🧭 30～39、🌳 40～49、🔥 50～59、🌾 60～69、🌙 70～79、✨ 80～89、🌌 90～100。Emoji 只作视觉导航，不为年龄段添加确定性心理标签。

每段必须使用 HTML：

```html
<table width="100%" style="width:100%; table-layout:fixed;">
<thead><tr>
<th width="8%" align="center">🎂 年龄</th>
<th width="12%" align="center">📆 年份</th>
<th width="18%" align="center">🧮 完整核算</th>
<th width="10%" align="center">牌面</th>
<th width="22%">中英文牌名</th>
<th width="30%">人生节点／备注</th>
</tr></thead>
```

所有段的列宽、居中方式和牌图宽度必须一致；第四列包含统一尺寸缩略图及牌名。不得因内容长而退回 Markdown Pipe Table，不得折叠、删年或只展示关键年份。若渲染器忽略 `style`，仍保留 `width="100%"` 和每个表头的 `width` 属性。

## 当前年度与生命牌序中的回声

第 04 章以 `📍 YOU ARE HERE` important Callout 显示年龄、年份、牌名、核心动作和日期区间，再展示上一年 → 当前年 → 下一年的关系。当前行在完整年表中加粗并标 `📍`。

取消连续窗口 Lifetime Loop。第 05 章依次呈现：核心牌回归时间轴、当前完整 Reset 阶段的卡片牌序、所有阶段总览。图表只编码年龄、年份、顺序与分组，绝不以牌号高度暗示强弱或人生质量。

## 交付检查

- 八章顺序正确，标题不超过 H3；身份卡能在 20～30 秒内读完。
- 重牌只呈现一次基础牌义，牌位功能分别解释。
- `📍 YOU ARE HERE`、`⭐` 与 `📍` 的语义和表格标记正确。
- 默认年表有 101 行，十个年龄段完整展开；每行均有年龄、年份、核算、牌名和牌图。
- 十个 HTML 表均为 100% 宽、fixed layout，六列宽度为 8%／12%／18%／10%／22%／30%。
- 核心牌回归、当前牌序、Reset 总览、焦点牌对话与年度复盘均完整。
- Mary 原书主题 → 现代语言 → 建设性资源 → 风险／阴影 → 现实问题的解释链清晰，且不作确定性预测。
