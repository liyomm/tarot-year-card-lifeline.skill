# 生命牌序中的回声

取消“寻找出现频率最高的连续四至八张牌”算法。年度牌序只表达出现顺序、年龄位置与 Reset 分组，不把牌号当作高低值。

## CORE CARD RETURNS｜核心牌回归

在 0～100 岁序列中查找性格牌、灵魂牌、隐藏／导师牌或特殊核心牌组再次成为年度牌的年龄。重合牌只呈现一次。每张核心牌一行，配牌图、年龄轴与回归节点；当前年龄附近节点使用金色强调。解释同一主题可能以不同成熟度回来，不宣称事件重复。

## CURRENT ARC｜当前十年牌序

Reset 定义为数字归约后从较高牌号进入较低起点的相邻转换。以两个 Reset 之间的完整牌序为一个阶段；展示当前年龄所在的完整阶段，不截取任意四张牌。

每个节点显示年龄、年份、牌名与一个动态生成的动作词。已走过、当前、下一入口用线框与底色同时区分。阶段名称根据实际牌序的起点、推进和收束动作生成。

## RESET｜阶段总览

展示所有阶段的年龄区间、起点牌、终点牌；当前阶段突出。只详细解释上一、当前与下一阶段，其他只保留总览。

## 验收

- 不存在 `Loop 01/02/03`、连续窗口频率或平移一格的重复切片。
- 不绘制高低折线，不用纵轴表示牌号。
- 性格牌与灵魂牌重合时只有一条核心回归时间轴。
- 当前阶段与当前年度可由年龄数据准确定位。
