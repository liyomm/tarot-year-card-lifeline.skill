# Personal Tarot Map PDF 设计系统

本规范用于 PDF 输出。内容顺序和数据必须与 Markdown 的八章架构一致；只允许因纸张、分页和打印阅读需要改变呈现方式，不改变 Mary K. Greer 计算、RWS 牌序、人生节点或解释边界。

## 视觉与字体

- 背景 `#FBF7EE`；主标题 `#2D2139`；强调 `#956C2C`；辅助 `#75627F`；正文 `#332C36`。
- 表头 `#EEE6D5`；提示框 `#FAF2DD`；人生节点 `#EEE8F2`；当前年份 `#F6E6B5`。
- 封面保留双线边框。正文页只保留顶部细线、页眉与页脚，不使用整页证书式边框。
- 长文、计算、年份、表格、来源和页眉页脚使用嵌入式宋体。引导语、书写问题和短提醒使用楷体。
- 所有标题和重要牌名必须使用真实 Bold 字体文件。若没有真实楷体粗体，标题回退到真实宋体 Bold，不得描边、偏移或重复绘制模拟粗体，也不得静默换成黑体。
- `assets/fonts/NotoSerifSC-Regular.ttf` 与 `NotoSerifSC-Bold.ttf` 是从开源 Noto Serif SC 可变字体的 400/700 权重生成的静态实例。楷体优先使用系统 KaiTi/STKaiti Regular；不存在时必须报错，不静默替换。
- PDF 不依赖字体提供彩色 emoji；把 `assets/emoji/` 中的本地图标作为行内或表格图像嵌入，避免方框与缺字，并让象征列表与 Markdown 保持同义。

第 02～04 章必须与 Markdown 使用同一内容数据，不得用旧版短摘要代替。生命灵数图、旬区高亮图、宫廷牌图、塔罗关系词云、当前年度牌和前后年度牌均须嵌入，并保持原始宽高比。

## 页面与章节

- 封面后按 01～08 顺序呈现：身份卡、个人象征语言、综合、当前位置、终身图谱、0～100 岁查询表、年度复盘、原书依据。
- 纵向正文使用 A4；0～100 岁查询表使用 A4 横向。横纵向切换时页码必须连续。
- 一级章节可另起页；二级内容自然衔接。使用 `keepWithNext` 与 `KeepTogether` 防止孤立标题和核心牌区块从段落中间断开。
- 每张核心牌依次呈现实际牌位含义、3～8 个可见象征和分点牌意；重牌只显示一次图像与基础牌义，再解释不同牌位功能。
- 年度复盘使用独立纵向打印页，保留足够手写空间。资料来源、字体说明和免责声明集中在最后部分。

## 生命牌序中的回声

PDF 不再使用高低折线或重复连续窗口 Loop。依次展示：每张核心牌的回归节点、当前完整 Reset 阶段的卡片牌序、全部阶段的带状总览。每个单元格显示年龄、年份、牌名与动作词；当前年份为浅金底，人生节点为浅紫底。

时间轴必须明确说明：牌号只是序列位置，用于观察循环，不代表吉凶、能量强弱或人生质量。不得通过纵轴高低制造价值暗示。

## 0～100 岁横向查询表

- 默认恰有 101 条记录，拆成五张横向页：0～20、21～40、41～60、61～80、81～100 岁。
- 表格宽度等于横向页面可打印区域。六列比例为 8%／12%／18%／10%／22%／30%：年龄、公历年份、核算过程、牌面、年度牌名称、人生节点／备注。
- 图片保持原始宽高比，统一尺寸；表头逐页重复。数字列居中，牌名和备注左对齐，全部单元格垂直居中。
- 使用交替浅色行；当前年龄整行浅金并标“当前”；用户节点整行浅紫并标“✦ 节点”。重合时当前色优先，备注同时保留节点。
- 整十岁行使用略粗暗金色横线。不得缩小正文表格字体来追求更少页数。
- 每张横向页页眉注明该页年龄与年份范围，页脚标注非强弱解释与连续页码。

## 强制验证

每次最终交付 PDF 前：

1. 使用 `pdffonts` 检查 Regular、Bold、Kai 字体均为嵌入或子集嵌入；标题必须来自真实 Bold 文件。
2. 使用 `pdfinfo` 确认页数，再把全部页面渲染成 PNG。
3. 生成全部页面的缩略图总览；单独检查封面、最密集正文页、时间轴页、查询表首／中／末页和来源页。
4. 检查乱码、缺字、符号方框、裁切、重叠、孤立标题、无意义大留白、牌图变形和页码不连续。
5. 用 PDF 文本与脚本数据核对：101 条年龄记录连续且无重复；牌号、牌名、图片文件一致；三本参考书及其职责完整。
6. 发现问题后修改并重新生成、重新渲染，不得直接交付第一次输出。
