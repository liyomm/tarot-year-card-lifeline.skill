# Personal Tarot Map｜个人塔罗生命地图

一套用于生成个人塔罗生命地图的 Codex Skill。它不进行随机抽牌，而是依据出生日期计算出生牌、年度牌与 0～100 岁生命牌序，并结合明确分工的塔罗对应体系生成简体中文 Markdown 或 PDF 报告。

## 主要内容

- 出生牌、性格牌、灵魂牌，以及符合规则时的隐藏／导师牌
- 19→10→1、22／0·4、14～18 夜间牌三种条件式特殊结构
- 上一年、当年和下一年的年度牌关系
- 0～100 岁共 101 行年度牌查询表
- 核心牌回归、阶段循环与生命回声
- 生命灵数、四元素机会牌、生日旬区、命运牌与撒比恩象征
- 太阳、月亮、上升对应的 Mary K. Greer 宫廷形象牌
- 年度复盘与自选焦点牌图像对话

## 使用方式

将整个目录放入 Codex 可读取的 Skills 目录，并在对话中调用 `tarot-year-card-lifeline`。生成前至少需要提供：

- 出生日期
- 年龄范围（默认 0～100 岁）
- 输出格式：Markdown、PDF 或两者
- 年度周期：生日周期、自然年或两种都看

姓名、真实人生节点、月亮星座与上升星座可以选填。完整行为规范与命令示例见 [SKILL.md](SKILL.md)。

## 方法边界

本 Skill 将 Mary K. Greer、T. Susan Chang 与黄金黎明宫廷牌资料的用途明确分开，不虚构引文或资料。生成内容用于象征性自我探索，不是随机占卜、宿命预测，也不替代医疗、法律、财务或心理专业意见。
